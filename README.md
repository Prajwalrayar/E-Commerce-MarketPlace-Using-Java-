# 🛒 E-Commerce Marketplace Using Java

A console-based E-Commerce Marketplace application built using Java. It allows customers to browse products, manage carts and wishlists, 
place orders, process payments, and track shipments while demonstrating core Java concepts.

## 🚀 Features
- Customer & Seller Management
- Product & Category Management
- Shopping Cart & Wishlist
- Order & Payment Processing
- Inventory & Shipment Management
- Coupon System
- Input Validation & Custom Exceptions

## 🛠️ Technologies
- Java
- OOPs
- Collections Framework
- Java Streams
- Exception Handling

## ▶️ Run
1. Clone the repository.
2. Open in IntelliJ IDEA or Eclipse.
3. Run `Main.java`.
